# บันทึกการตัดสินใจแทนเจ้าหน้าที่การเงิน

ระบบบริหารจัดเก็บเงินบำรุงการศึกษา โรงเรียนวัดเสาหิน จังหวัดเชียงใหม่

| รายการ | รายละเอียด |
|---|---|
| วันที่ | 21 พฤศจิกายน 2569 |
| ที่มา | ผู้รับผิดชอบโครงการ (ไม่ได้ทำหน้าที่การเงิน) มอบให้ผู้พัฒนาตัดสินใจแทนเจ้าหน้าที่การเงิน โดยให้ยึดระเบียบ |
| สถานะ | ใช้พัฒนาได้ทันที แต่ **ต้องให้ผู้มีหน้าที่การเงินลงนามยืนยันแบบตรวจท้ายเอกสารนี้ก่อนใช้งานจริง** |

## หลักการที่ใช้ตัดสินใจ

1. **เลือกทางที่เข้มงวดกว่าเสมอ**
   ทางที่เข้มกว่ามักไม่ขัดระเบียบ และผ่อนภายหลังได้ ส่วนทางที่หละหลวมแก้ย้อนหลังไม่ได้
2. **ระบบไม่เป็นผู้ตัดสินความชอบด้วยระเบียบ**
   เรื่องที่ระบบตัดสินแทนคนไม่ได้ (เช่น อัตราที่เก็บได้) ระบบจะบังคับให้แนบเลขที่หนังสืออนุมัติแทน
3. **เกือบทุกข้อปรับได้ภายหลังในหน้าตั้งค่า** โดยไม่ต้องแก้โค้ด และทุกการปรับมีประวัติ
4. **ไม่อ้างว่าข้อใด "ถูกระเบียบ" ถ้ายังไม่ได้เห็นตัวบท**
   ผู้พัฒนาค้นแล้วพบชื่อระเบียบหลักและเอกสารประกอบ แต่**เปิดอ่านตัวบทรายข้อไม่ได้** (ดูหัวข้อแหล่งข้อมูล)
   ข้อที่ขึ้นกับระเบียบจึงมีเครื่องหมาย ⚖️ ให้ตรวจยืนยัน

## การตัดสินใจ

⚖️ = ขึ้นกับระเบียบ ต้องยืนยันในแบบตรวจท้ายเอกสาร

ถ้าข้อใดไม่ตรง ให้แจ้งผู้พัฒนาเพื่อปรับ (ส่วนใหญ่ปรับได้ในหน้าตั้งค่า)

| ✓ | เรื่องที่ต้องยืนยัน | อ้างอิงการตัดสินใจ |
|---|---|---|
| ☐ | อัตราและรายการเงินบำรุงการศึกษาที่โรงเรียนเก็บได้ รอบการเก็บ และเอกสารที่อนุมัติ | D-05, D-06 |
| ☐ | หลักเกณฑ์การลดหย่อนหรือยกเว้น และเอกสารที่ต้องใช้ | D-07 |
| ☐ | วิธีปฏิบัติกับใบเสร็จที่เขียนผิดหรือยกเลิก และกรณีที่ผู้อนุมัติไม่อนุมัติการยกเลิก | D-13, D-32 |
| ☐ | การใช้ใบเสร็จเรียงเลขที่ การใช้ข้ามปีงบประมาณ และการปิดเล่ม | D-11, D-15, D-16 |
| ☐ | ผู้มีอำนาจอนุมัติแต่ละรายการ | D-17 |
| ☐ | ผู้ลงนามในรายงานรับเงินประจำวัน กำหนดเวลานำเงินฝาก และผู้มีอำนาจเปิดยอดประจำวันใหม่ | D-19, D-20, D-37 |
| ☐ | การออกใบเสร็จสำหรับเงินโอน | D-04 |
| ☐ | การคืนเงิน และการยกเลิกหนี้ของนักเรียนที่ย้ายออก | D-09, D-10 |
| ☐ | นักเรียนที่ย้ายออกระหว่างภาคเรียนต้องชำระเงินบำรุงของภาคนั้นหรือไม่ | D-27 |
| ☐ | การบันทึกรับเงินย้อนหลัง และระยะเวลาที่ยอมให้บันทึกย้อนหลัง | D-30 |
| ☐ | การนำข้อมูลก่อนเริ่มใช้ระบบเข้าระบบ และการติดตามยอดค้างของปีก่อนเริ่มใช้ระบบ | D-45 |
| ☐ | ถ้อยคำและผู้ลงนามในเอกสารแจ้งยอด | D-21, D-43 |
| ☐ | ระยะเวลาเก็บรักษาข้อมูลและไฟล์สำรอง และการแจ้งผู้ปกครองเรื่องข้อมูลส่วนบุคคล | D-02, D-22, D-26, D-41 |

## แหล่งข้อมูลที่ค้นประกอบการตัดสินใจ

ผู้พัฒนาค้นเมื่อ 21 พฤศจิกายน 2569 **ไม่พบตัวบทรายข้อที่เปิดอ่านได้** จึงใช้ข้อมูลเหล่านี้เป็นแนวทางเท่านั้น:

- ระเบียบกระทรวงการคลังว่าด้วยการเบิกเงินจากคลัง การรับเงิน การจ่ายเงิน การเก็บรักษาเงิน และการนำเงินส่งคลัง พ.ศ. 2562 (ประกาศในราชกิจจานุเบกษา 13 พฤษภาคม 2562) ระเบียบหลักด้านการรับเงินของส่วนราชการ **ยังไม่ได้อ่านตัวบทฉบับเต็ม**
- แนวทางการควบคุมภายในด้านการรับเงิน (กรมบัญชีกลาง ธันวาคม 2562) พบเอกสาร แต่เปิดจากเครือข่ายของระบบพัฒนาไม่ได้: [web.kmutt.ac.th](https://web.kmutt.ac.th/internal-audit/Upload/ICF27122019)
- ข่าวประกาศกระทรวงศึกษาธิการเรื่องการเก็บเงินบำรุงการศึกษา (ปีการศึกษา 2551 เพดานรายภาคเรียน) **ไม่ทราบว่ายังใช้บังคับหรือมีฉบับใหม่แทน**: [mgronline.com](https://mgronline.com/qol/detail/9510000080255)
- เอกสารและแบบฟอร์มการเงินของสถานศึกษาที่เผยแพร่ เช่น ทะเบียนคุมใบเสร็จใช้ต่อเนื่องหลายปีงบประมาณและมียอดยกมา (เป็นแนวปฏิบัติของหน่วยงานอื่น ไม่ใช่ตัวระเบียบ): [ตัวอย่างแฟ้มเอกสารการเงินโรงเรียน](https://docs.google.com/document/d/1HjRuedKCDaTfpUQabaS8fM34k8fTrXJ8/export?format=pdf), [ข้อสังเกตจากการตรวจสอบภายในสถานศึกษา](https://www.gotoknow.org/posts/209465)
