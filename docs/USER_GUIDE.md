# คู่มือผู้ใช้

ระบบบริหารจัดเก็บเงินบำรุงการศึกษา โรงเรียนวัดเสาหิน จังหวัดเชียงใหม่ (เวอร์ชัน 1.0.1)

> ระบบนี้เป็น**ทะเบียนคุมและบันทึกอ้างอิง**ของใบเสร็จรับเงินจากเล่มจริงของทางราชการ ไม่ออกใบเสร็จแทนเล่มจริง
> ทุกการเพิ่ม แก้ไข ยกเลิก และอนุมัติ มีประวัติว่าใครทำเมื่อไร ข้อมูลการเงินที่บันทึกแล้วลบไม่ได้

| บทบาท | ทำอะไร | อ่านหัวข้อ |
|---|---|---|
| ทุกคน | เข้าสู่ระบบ เปลี่ยนรหัสผ่าน ใช้บนมือถือ | 1 |
| ผู้ดูแลระบบ | ผู้ใช้ ตั้งค่า ปีการศึกษา สำรอง/กู้คืน ตรวจความถูกต้อง | 2 |
| เจ้าหน้าที่การเงิน | นักเรียน เรียกเก็บ รับเงิน ใบเสร็จ ปิดยอด รายงาน | 3 |
| ผู้อำนวยการ | Dashboard อนุมัติ ลงนามรายงาน ตรวจสอบ | 4 |

## 1. เริ่มต้นใช้งาน (ทุกคน)

### เข้าสู่ระบบ

1. เปิดลิงก์ของระบบที่ผู้ดูแลระบบให้ (ลงท้ายด้วย `/exec`) ต้องเข้าสู่ระบบ Google ก่อน
2. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** → กด **เข้าสู่ระบบ**
3. ครั้งแรกระบบให้ตั้งรหัสผ่านใหม่ (อย่างน้อย 8 ตัว มีทั้งตัวอักษรและตัวเลข)

| ตัวเลือกที่หน้าเข้าสู่ระบบ | ความหมาย |
|---|---|
| จดจำชื่อผู้ใช้ในเครื่องนี้ | ครั้งต่อไปกรอกเฉพาะรหัสผ่าน (ระบบไม่จำรหัสผ่าน) |
| อยู่ในระบบต่อในเครื่องนี้ | ปิดเบราว์เซอร์แล้วเปิดใหม่ไม่ต้องเข้าสู่ระบบ จนครบเวลาที่โรงเรียนกำหนด (ค่าเริ่มต้น 8 ชั่วโมง) **เลือกเฉพาะเครื่องส่วนตัวเท่านั้น** |

- เปิดลิงก์แล้วขึ้น **"Sorry, unable to open the file at this time"** และในลิงก์มี `/u/1/` หรือ `/u/2/` แปลว่าเบราว์เซอร์เข้าสู่ระบบ Google ไว้หลายบัญชี
  ให้ลบ `u/1/` หรือ `u/2/` ออกจากลิงก์ (เหลือ `script.google.com/macros/s/…/exec`) หรือเปิดในหน้าต่างไม่ระบุตัวตน (Incognito) ที่เข้าสู่ระบบ Google บัญชีเดียว
  แนะนำให้สร้าง**โปรไฟล์ Chrome แยก**สำหรับบัญชีที่ใช้กับระบบนี้ แล้วบุ๊กมาร์กลิงก์ที่ไม่มี `/u/…/`
- ใส่รหัสผ่านผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที
- ลืมรหัสผ่าน: ติดต่อผู้ดูแลระบบให้รีเซ็ต
- ไม่ได้ใช้งาน 30 นาที ระบบออกจากระบบเอง (ถ้าไม่ได้เลือกอยู่ในระบบต่อ)
- เครื่องที่ใช้ร่วมกัน: กด **ออกจากระบบ** ทุกครั้ง

### บนมือถือ

- กดปุ่ม ☰ มุมซ้ายบนเพื่อเปิดเมนู
- ตารางแสดงเป็นการ์ดทีละรายการ
- ใช้ได้ทุกหน้า แต่การพิมพ์รายงานแนะนำให้ใช้คอมพิวเตอร์

### รูปแบบตัวเลขและวันที่

- เงินแสดงเป็น `1,000.00 บาท` วันที่เป็นวันเดือนปี พ.ศ.
- ปีการศึกษาในรายงานตามวันที่รับเงินคือ 1 พ.ค.–30 เม.ย. ปีงบประมาณคือ 1 ต.ค.–30 ก.ย.

## 2. ผู้ดูแลระบบ

ผู้ดูแลระบบ**ไม่เห็นข้อมูลการเงิน**ตามหลักสิทธิ์น้อยที่สุด

### 2.1 ผู้ใช้งาน

| งาน | วิธีทำ |
|---|---|
| เพิ่มผู้ใช้ | **ผู้ใช้งาน → เพิ่มผู้ใช้** เลือกบทบาท ตั้งรหัสผ่านชั่วคราว แล้วแจ้งผู้ใช้เป็นการส่วนตัว |
| ผู้ใช้ลืมรหัสผ่าน | คลิกผู้ใช้ → **รีเซ็ตรหัสผ่าน** |
| ผู้ใช้ย้าย/ลาออก | คลิกผู้ใช้ → **ปิดการใช้งาน** (ไม่ลบ เพื่อให้ประวัติยังอ่านได้) |

- 1 คน 1 บัญชี 1 บทบาท ถ้าคนเดียวทำหลายหน้าที่ ให้สร้างหลายบัญชี
- ผู้ดูแลระบบลืมรหัสผ่านเอง: เจ้าของระบบใช้เมนูใน Google Sheets **3) สร้างหรือรีเซ็ตบัญชีผู้ดูแลระบบ**

### 2.2 ตั้งค่าโรงเรียน

| กลุ่ม | ต้องตรวจ |
|---|---|
| ข้อมูลโรงเรียน | ชื่อ ที่อยู่ เบอร์โทร สังกัด (พิมพ์ในรายงานและหนังสือแจ้งยอด) |
| ผู้ลงนามในเอกสาร | ชื่อและตำแหน่งผู้อำนวยการ และเจ้าหน้าที่การเงิน |
| การเรียนการสอนและการรับเงิน | ระดับชั้นที่เปิดสอน (เรียงจากต่ำไปสูง) ช่องทางการรับเงิน |
| รายการที่ต้องให้ผู้อำนวยการอนุมัติ | ค่าเริ่มต้น: ต้องอนุมัติทุกรายการ (แนะนำให้คงไว้) |
| ใบเสร็จรับเงิน | เตือนเมื่อเลขที่เหลือน้อย และใช้เลขที่เรียงลำดับเคร่งครัด |
| ความปลอดภัย | เวลาออกจากระบบอัตโนมัติ อายุการเข้าสู่ระบบ การล็อกเมื่อใส่รหัสผิด อนุญาต "อยู่ในระบบต่อ" |
| การสำรองข้อมูล | จำนวนไฟล์สำรองอัตโนมัติที่เก็บ (ค่าเริ่มต้น 60) |

### 2.3 ปีการศึกษา

- ต้นปีการศึกษา: **ปีการศึกษา → เพิ่มปีการศึกษา** → ตั้งเป็นปีปัจจุบัน (เจ้าหน้าที่การเงินจึงเลื่อนชั้นนักเรียนได้)
- ปิดปีที่จบแล้วได้ (คลิกปี → แก้ไข → สถานะ "ปิดแล้ว") ปีที่ปิดยังรับชำระหนี้ค้างได้ แต่ตั้งอัตราหรือเรียกเก็บเพิ่มไม่ได้

### 2.4 สำรองและกู้คืนข้อมูล

- ระบบสำรองอัตโนมัติทุกวัน 18:00–19:00 น. ไปที่ Google ไดรฟ์ของบัญชีเจ้าของระบบ (**ห้ามแชร์โฟลเดอร์สำรอง**)
- หน้าแรกเตือนเมื่อสำรองไม่สำเร็จ หรือไม่มีการสำรองเกิน 2 วัน
- **สำรองข้อมูลตอนนี้**: ใช้ก่อนงานใหญ่ เช่น นำเข้าข้อมูลจำนวนมาก หรือขึ้นปีการศึกษาใหม่
- **กู้คืน** (ใช้เมื่อข้อมูลเสียหายเท่านั้น):
  1. แจ้งทุกคนให้หยุดบันทึก
  2. เลือกไฟล์ → **กู้คืน…** → อ่านผลกระทบ (จำนวนรายการที่จะหายไป)
  3. พิมพ์ "กู้คืนข้อมูล" → กดกู้คืน ระบบเก็บข้อมูลปัจจุบันเป็นไฟล์ "ก่อนกู้คืน" ให้เสมอ
  4. ทุกคนเข้าสู่ระบบใหม่ เจ้าหน้าที่การเงินบันทึกรายการรับเงินหลังเวลาสำรองใหม่ตามสำเนาใบเสร็จ
  5. กู้คืนผิดไฟล์: กู้คืนจากไฟล์ "ก่อนกู้คืน" ล่าสุด
- บัญชีผู้ใช้และประวัติการใช้งานไม่ถูกย้อนเมื่อกู้คืน

### 2.5 ประวัติการใช้งานและการตรวจความถูกต้อง

- **ประวัติการใช้งาน**: ดูว่าใครทำอะไรเมื่อไร ค่าเดิมและค่าใหม่ กด **ตรวจความถูกต้องของประวัติ** เพื่อดูว่ามีการแก้ชีตประวัติหรือไม่
- **ตรวจความถูกต้องของข้อมูล**: ตรวจ 8 ข้อทั้งระบบ (ยอดเงิน เลขที่ใบเสร็จ สถานะเล่ม วันที่ปิดยอดแล้ว ฯลฯ) ระบบตรวจให้อัตโนมัติทุกวัน และเตือนที่หน้าแรก
- พบปัญหา: ห้ามแก้ชีตเอง แจ้งผู้อำนวยการ แล้วตรวจจากประวัติการใช้งาน (หน้าตรวจความถูกต้องมีขั้นตอน)

### 2.6 งานประจำของผู้ดูแลระบบ

| ความถี่ | งาน |
|---|---|
| ทุกวัน | ดูหน้าแรก: สำรองข้อมูลสำเร็จ และตรวจความถูกต้องผ่าน |
| ทุกเดือน | ดาวน์โหลดไฟล์สำรองล่าสุดเก็บแยก (เจ้าของระบบ: Google ไดรฟ์ → คลิกขวา → ดาวน์โหลด) และตรวจรายชื่อผู้ใช้ที่ยังเปิดอยู่ |
| ต้นปีการศึกษา | เพิ่มปีการศึกษาใหม่ ตั้งเป็นปีปัจจุบัน สำรองข้อมูลก่อนเลื่อนชั้น |
| ทุกครั้งที่อัปเดตระบบ | ทำตาม [INSTALL.md](INSTALL.md) และกดเมนู **4) ตรวจความพร้อมของระบบ** |

## 3. เจ้าหน้าที่การเงิน

### 3.1 ต้นปีการศึกษา / ต้นภาคเรียน

1. **นักเรียน → นำเข้าข้อมูล**: เลือกไฟล์ Excel หรือ CSV → ตรวจตารางก่อนนำเข้า (รายการซ้ำและขัดแย้งต้องเลือกว่าข้ามหรืออัปเดต) → บันทึก
2. ปีการศึกษาใหม่: **นักเรียน → เลื่อนชั้น** (ชั้นสุดท้ายเป็น "จบการศึกษา") หนี้ปีเก่ายังอยู่และแสดงเป็น "ค้างจากปีก่อน"
3. **อัตราและการเรียกเก็บ → ตั้งอัตรา**: เลือกปี ภาคเรียน ชั้น จำนวนเงิน วันเริ่มและวันครบกำหนด และ**เลขที่หนังสือ/มติที่อนุมัติอัตรา** (บังคับ)
4. กด **เรียกเก็บ** ที่อัตรานั้น → ตรวจรายชื่อ → ยืนยัน
5. **เล่มใบเสร็จ → ลงทะเบียนเล่ม** ตามเล่มจริง (เลขเล่ม เลขที่เริ่ม-สิ้นสุด) → **เปิดใช้**

### 3.2 รับชำระเงิน (ทุกวัน)

1. **รับชำระเงิน** → ค้นหานักเรียน (ชื่อ เลขประจำตัว หรือห้อง)
2. **เขียนใบเสร็จจริงก่อน** ระบบแสดงเลขเล่มและเลขที่ถัดไปที่ต้องใช้
3. กรอกวันที่ จำนวนเงิน ช่องทาง (โอนต้องกรอกเลขอ้างอิง) ผู้รับเงิน
4. ระบบตัดชำระหนี้เก่าก่อนอัตโนมัติ (แก้ได้) ยอดตัดชำระรวมต้องเท่ากับจำนวนเงินที่รับ
5. ติ๊ก **ตรวจสอบใบเสร็จฉบับจริงแล้ว** → **บันทึกการรับเงิน**

| สถานการณ์ | ทำอย่างไร |
|---|---|
| ใบเสร็จเขียนผิดหรือชำรุด (ยังไม่บันทึก) | หน้ารับเงิน → **ใบเสร็จเลขที่ … เขียนผิดหรือชำรุด? ยกเลิกเลขที่นี้** เก็บใบเสร็จฉบับที่ยกเลิกไว้ครบทุกส่วน |
| ใบเสร็จที่บันทึกแล้วต้องยกเลิกทั้งฉบับ | **รายการรับเงิน** → คลิกรายการ → **ขอยกเลิกใบเสร็จ** |
| ใบเสร็จจริงถูกต้อง แต่บันทึกในระบบผิด | คลิกรายการ → **ขอแก้ไขรายการ** (เลขที่ใบเสร็จไม่เปลี่ยน) |
| ลดหย่อนหรือยกเว้น | บัญชีนักเรียน → รายการเรียกเก็บ → **ลดหย่อน/ยกเว้น** พร้อมเหตุผลและเอกสารอ้างอิง |
| เล่มชำรุด ต้องปิดก่อนใช้ครบ | เล่มใบเสร็จ → คลิกเล่ม → **ขอปิดเล่มก่อนใช้ครบ** |
| ระบบแจ้งเลขที่ขาดช่วง | ตรวจกับเล่มจริง แล้วบันทึกรับเงินหรือยกเลิกเลขที่นั้น |

- คำขอทั้งหมดรอผู้อำนวยการอนุมัติ ระหว่างรอ ยอดเดิมยังมีผล ติดตามได้ที่ **คำขออนุมัติ**
- ระบบไม่รับเงินเกินยอดค้าง และกันการบันทึกซ้ำเมื่อกดซ้ำหรือเน็ตหลุด

### 3.3 สิ้นวัน: ปิดยอดประจำวัน

1. **รายงานและปิดยอด → รายงานการรับเงินประจำวัน**
2. กด **พิมพ์ / บันทึก PDF** → ตรวจรายงานกับ**เงินที่นับได้**และ**สำเนาใบเสร็จ**ทุกฉบับ
3. ผู้รับเงิน ผู้ตรวจสอบ และผู้อำนวยการลงนามในรายงาน
4. กด **ปิดยอดวันนี้** → ติ๊กยืนยัน → ปิดยอด รายงานจะมี **รหัสตรวจสอบ** ท้ายกระดาษ
5. เก็บรายงานที่ลงนามแล้วตามระเบียบของโรงเรียน

- ปิดยอดไม่ได้ถ้ายังมีคำขอยกเลิก/แก้ไขใบเสร็จของวันนั้นรอพิจารณา
- หลังปิดยอด บันทึกหรือแก้ไขรายการของวันนั้นไม่ได้ ถ้าจำเป็น ให้ผู้อำนวยการ **เปิดยอดใหม่** พร้อมเหตุผล แล้วปิดยอดใหม่หลังแก้ไข
- หน้าแรกเตือนวันที่รับเงินแล้วแต่ยังไม่ปิดยอด (30 วันล่าสุด)

### 3.4 ติดตามยอดค้างและแจ้งผู้ปกครอง

- **ยอดค้างชำระ**: เลือกปีการศึกษา คลิกชั้น/ห้องเพื่อดูรายชื่อ ติ๊ก "เฉพาะที่เลยกำหนด" ได้
- **รายงานและปิดยอด → เอกสารแจ้งยอดเรียกเก็บเงิน**: เลือกชั้น/ห้อง → พิมพ์ 1 หน้าต่อนักเรียน 1 คน หรือกดจากบัญชีนักเรียน → **พิมพ์หนังสือแจ้งยอด**
- ถ้อยคำในหนังสือเป็นการแจ้งให้ทราบอย่างสุภาพ ผู้อำนวยการควรตรวจก่อนใช้ครั้งแรก

### 3.5 รายงาน

| รายงาน | ใช้เมื่อ |
|---|---|
| รายงานการรับเงินประจำวัน | ทุกวัน (ปิดยอด) |
| รายงานการรับเงินแยกตามห้อง / ระดับชั้น | รายเดือน รายปีการศึกษา หรือปีงบประมาณ |
| รายงานยอดค้างชำระ | ติดตามหนี้ เสนอผู้อำนวยการ |
| รายงานทะเบียนคุมใบเสร็จ | ตรวจเล่มใบเสร็จ ทุกเลขที่ |
| รายงานใบเสร็จยกเลิก | ตรวจการยกเลิกและผลการพิจารณา |
| รายงานสรุปประจำปีการศึกษา | สิ้นปีการศึกษา |
| รายงานการใช้ใบเสร็จประจำปีงบประมาณ | สิ้นปีงบประมาณ (30 ก.ย.) |

บันทึกเป็น PDF: กด **พิมพ์ / บันทึก PDF** → ปลายทาง **บันทึกเป็น PDF** → ขนาดกระดาษ A4 → ปิด "ส่วนหัวและส่วนท้าย"

## 4. ผู้อำนวยการ

### 4.1 ภาพรวม (Dashboard)

- เลือกปีการศึกษา ดูจำนวนนักเรียน ยอดเรียกเก็บ ยอดรับ ยอดค้าง จำนวนผู้ชำระครบ บางส่วน และยังไม่ชำระ
- แท่งความคืบหน้ารายชั้น/รายห้อง: ความยาวแท่ง = ยอดที่รับแล้ว ÷ ยอดเรียกเก็บสุทธิ ชี้ที่แท่งเพื่อดูตัวเลข หรือกด "ดูเป็นตารางตัวเลข"

### 4.2 พิจารณาคำขออนุมัติ

1. **คำขออนุมัติ** (หน้าแรกแสดงจำนวนคำขอค้าง) → **พิจารณา**
2. อ่านเหตุผล เอกสารอ้างอิง และตาราง "ค่าเดิมและค่าที่ขอแก้ไข"
3. **อนุมัติ** หรือ **ไม่อนุมัติ** (ต้องกรอกเหตุผล)

- ระบบตรวจยอดเงินล่าสุดอีกครั้งตอนอนุมัติ ถ้ายอดเปลี่ยนไปแล้วจะอนุมัติไม่ได้
- คำขอที่ตนเองยื่น พิจารณาเองไม่ได้

### 4.3 ลงนามรายงานประจำวันและเปิดยอดใหม่

- ตรวจรายงานรับเงินประจำวันที่เจ้าหน้าที่พิมพ์ (รหัสตรวจสอบท้ายกระดาษใช้เทียบกับระบบภายหลัง)
- ถ้าต้องแก้รายการของวันที่ปิดยอดแล้ว: **รายงานและปิดยอด → รายงานการรับเงินประจำวัน** เลือกวันที่ → **เปิดยอดใหม่** พร้อมเหตุผล
- ถ้ารายงานแจ้งว่า "ไม่ตรงกับตอนปิดยอด" แปลว่ามีการแก้ข้อมูลในชีตโดยตรง ให้ตรวจจากประวัติการใช้งานทันที

### 4.4 ตรวจสอบ

| เมนู | ใช้ตรวจ |
|---|---|
| ประวัติการใช้งาน | ใครทำอะไร เมื่อไร ค่าเดิมและค่าใหม่ |
| ตรวจความถูกต้องของข้อมูล | ยอดเงิน เลขที่ใบเสร็จ สถานะเล่ม และวันที่ปิดยอดแล้วถูกต้องทั้งระบบ |
| รายงานใบเสร็จยกเลิก | การยกเลิกทั้งหมดและผลการพิจารณา |
| รายงานทะเบียนคุมใบเสร็จ | เทียบกับเล่มใบเสร็จจริง |

| ทำไมผู้ดูแลระบบไม่เห็นเมนูการเงิน | ตามหลักสิทธิ์น้อยที่สุด ผู้ดูแลระบบจัดการระบบ ไม่ใช่ข้อมูลการเงิน |
