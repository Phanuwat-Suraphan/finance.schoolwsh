# คู่มือติดตั้งและทดสอบ

ระบบบริหารจัดเก็บเงินบำรุงการศึกษา โรงเรียนวัดเสาหิน จังหวัดเชียงใหม่

> ปัจจุบันครอบคลุม **ระยะที่ 1: โครงสร้างระบบและฐานข้อมูล**
> ในระยะนี้ **ยังไม่ต้อง Deploy เว็บแอป** เพราะยังไม่มีระบบ Login (มาในระยะที่ 2)

---

## วิธีติดตั้ง (ง่ายที่สุด: วางไฟล์เดียว)

ทั้งระบบรวมอยู่ในไฟล์เดียวคือ [`dist/Code.gs`](../dist/Code.gs) คัดลอกไปวางครั้งเดียวแล้วกดปุ่ม Run ครั้งเดียว

### เตรียมก่อนเริ่ม

1. **บัญชี Google ที่จะเป็นเจ้าของระบบ**
   - แนะนำบัญชีกลางของโรงเรียน ไม่ใช่บัญชีส่วนตัวของครู
   - เปิด 2-Step Verification (การยืนยันแบบ 2 ขั้นตอน)
2. **ไฟล์ Google Sheets ที่สร้างไว้** เปิดด้วยบัญชีเจ้าของระบบ
3. **ใช้คอมพิวเตอร์** และให้เบราว์เซอร์ login บัญชี Google ไว้เพียงบัญชีเดียว
   ถ้า login หลายบัญชีพร้อมกัน Google อาจรันสคริปต์ด้วยบัญชีอื่นแล้วเกิดข้อผิดพลาดเรื่องสิทธิ์

### 4 ขั้นตอน

**1. เปิด Apps Script**
ใน Google Sheets ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**

**2. คัดลอกโค้ด**
1. เปิดไฟล์ [`dist/Code.gs`](../dist/Code.gs) บน GitHub
2. กดปุ่ม **Copy raw file** (ไอคอนสี่เหลี่ยมซ้อนกัน มุมขวาบนของกล่องโค้ด)

**3. วางโค้ด**
1. ในหน้า Apps Script คลิกในไฟล์ `Code.gs`
2. กด **Ctrl+A** (เลือกทั้งหมด) แล้ว **Ctrl+V** (วางทับ)
3. กด **Ctrl+S** (บันทึก)

บน Mac ใช้ ⌘ แทน Ctrl

**4. กด Run**
1. แถบด้านบนของโค้ด ช่องรายชื่อฟังก์ชันต้องเป็น **`SetupDatabase`** (ถ้าไม่ใช่ ให้เลือก)
2. กด **▶ เรียกใช้ (Run)**
3. ครั้งแรกเท่านั้น Google จะขออนุญาต:
   1. กด **ตรวจสอบสิทธิ์ (Review permissions)** แล้วเลือกบัญชีเจ้าของระบบ
   2. ถ้าเห็นข้อความว่า Google ยังไม่ได้ยืนยันแอปนี้ (Google hasn't verified this app) ให้กด **ขั้นสูง (Advanced)** แล้วกดลิงก์ **ไปที่ ... (ไม่ปลอดภัย)**
      ข้อความนี้ปรากฏกับสคริปต์ที่โรงเรียนเขียนเองทุกตัว ไม่ใช่ไวรัส
   3. กด **อนุญาต (Allow)**
4. ถ้ารอบแรกหยุดไปเพราะขออนุญาต ให้กด **▶ เรียกใช้** อีกครั้ง
5. ช่อง **บันทึกการดำเนินการ (Execution log)** ด้านล่างจะแสดง **ผลการติดตั้งฐานข้อมูล … สร้างชีตใหม่ 15 ชีต**

**เสร็จแล้ว:** กลับไปที่ Google Sheets จะเห็นแท็บชีตของระบบ 15 แท็บ

สิทธิ์ที่ระบบขอ มีเท่านี้:

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| Google Sheets | อ่านและเขียนไฟล์ฐานข้อมูล |
| แสดงเมนูและกล่องข้อความใน Google Sheets | เมนูของระบบ |
| ดูอีเมลของบัญชี | ตรวจว่าผู้สั่งติดตั้งเป็นเจ้าของระบบ |

### อัปเดตเมื่อมีเวอร์ชันใหม่

ทำ **ขั้นตอนที่ 2–4 ซ้ำ** (คัดลอก → วางทับทั้งหมด → บันทึก → Run `SetupDatabase`)

- ข้อมูลเดิมไม่หาย และค่าที่ตั้งไว้ไม่ถูกเขียนทับ
- ระบบเพิ่มชีต คอลัมน์ หรือค่าตั้งค่าใหม่ให้เอง
- ถ้าเวอร์ชันใหม่ใช้สิทธิ์เพิ่ม Google จะขออนุญาตอีกครั้ง

## ตรวจผลการติดตั้ง

- [ ] มีแท็บชีตครบ 15 ชีต:
  `Users`, `SchoolSettings`, `AcademicYears`, `Students`, `Enrollments`, `FeeSettings`, `FeeAssessments`, `FeeAdjustments`, `Payments`, `PaymentAllocations`, `ReceiptBooks`, `ReceiptEntries`, `ReceiptCancellations`, `ApprovalRequests`, `AuditLogs`
- [ ] แถวแรกของทุกชีตเป็นหัวตารางพื้นสีกรมท่า ตัวอักษรสีขาว ชี้เมาส์ที่หัวคอลัมน์จะเห็นคำอธิบายภาษาไทย
- [ ] ชีต `SchoolSettings` มี 23 แถว และค่า `CURRENT_ACADEMIC_YEAR` เป็น `2569`
- [ ] ชีต `AuditLogs` มี 24 แถว (ค่าตั้งค่า 23 แถว + การติดตั้ง 1 แถว) และทุกแถวมีค่าในคอลัมน์ `Hash`
- [ ] ลองพิมพ์ในเซลล์ว่างของชีตใดก็ได้ Google จะเตือนว่าเป็นช่วงที่ได้รับการป้องกัน ให้กด **ยกเลิก (Cancel)**

> ⚠️ ใน Apps Script ที่ **⚙️ การตั้งค่าโปรเจกต์ → คุณสมบัติของสคริปต์ (Script Properties)** จะมีค่า `PASSWORD_PEPPER`
> **ห้ามแก้ ลบ หรือเปิดเผยค่านี้** ระยะที่ 2 ใช้ค่านี้แฮชรหัสผ่าน ถ้าค่าเปลี่ยน รหัสผ่านของทุกคนจะใช้ไม่ได้

## ทดสอบเพิ่มเติม (ไม่บังคับ ทำได้เฉพาะก่อนใช้งานจริง)

**รันซ้ำต้องไม่ทำลายข้อมูล**

1. กด **▶ เรียกใช้** `SetupDatabase` อีกครั้ง
2. ผลต้องเป็น **โครงสร้างครบถ้วน ไม่มีการเปลี่ยนแปลง** และ `SchoolSettings` ยังมี 23 แถว

**ระบบตรวจพบการแก้ประวัติด้วยมือ**

1. รีเฟรชหน้า Google Sheets รอให้เมนู **ระบบเงินบำรุงการศึกษา** ปรากฏ
2. เลือก **2) ตรวจสอบความถูกต้องของประวัติการใช้งาน** ผลต้องเป็น **ถูกต้อง**
3. ที่ชีต `AuditLogs` พิมพ์คำใดก็ได้ในคอลัมน์ `Note` ของแถวที่ 5 (ยอมรับคำเตือน)
4. เลือกเมนู **2)** อีกครั้ง ระบบต้องแจ้ง **แถว 5: ข้อมูลในแถวนี้ถูกแก้ไขหลังบันทึก**
5. กด **Ctrl+Z** คืนค่าเดิม แล้วตรวจอีกครั้ง ผลต้องกลับมาเป็น **ถูกต้อง**

## ข้อห้ามหลังติดตั้ง

| ห้าม | เหตุผล |
|---|---|
| แชร์ไฟล์ Google Sheets หรือโปรเจกต์ Apps Script ให้ผู้อื่นแก้ไข | ผู้ใช้ทุกคนต้องเข้าผ่านเว็บแอปเท่านั้น ระบบจึงควบคุมสิทธิ์และบันทึกประวัติได้ |
| เปลี่ยนชื่อชีต หรือชื่อหัวคอลัมน์ | โค้ดอ้างอิงตามชื่อ |
| จัดเรียง (Sort) หรือลบแถวในชีต | ข้อมูลการเงินต้องไม่ถูกลบ (ถ้าแถวถูกย้าย ระบบจะหยุดการบันทึกเพื่อป้องกันข้อมูลผิดแถว) |
| แก้ข้อมูลในชีตด้วยมือ | ข้ามการตรวจสิทธิ์และไม่มีประวัติ (การแก้ AuditLogs จะถูกตรวจพบ) |
| แก้หรือลบค่าใน Script Properties | ระบบจะเปิดฐานข้อมูลหรือตรวจรหัสผ่านไม่ได้ |

## สำหรับผู้พัฒนา

### โครงสร้างโค้ด

- ซอร์สโค้ดแยกไฟล์ตามหน้าที่อยู่ใน `src/` แก้ไขที่นี่เท่านั้น
- `dist/Code.gs` สร้างจาก `src/` อัตโนมัติ ห้ามแก้โดยตรง

ทุกครั้งที่แก้ `src/` ให้สร้างไฟล์รวมใหม่:

```bash
npm run build
```

### รันชุดทดสอบอัตโนมัติ (ไม่ต้องเชื่อมต่อ Google)

ต้องมี Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm test
```

- ชุดทดสอบใน `tests/` รันโค้ดจริงกับ Google Sheets จำลอง (`tests/harness.js`)
- ตรวจด้วยว่า `dist/Code.gs` ตรงกับ `src/` และติดตั้งได้เมื่อวางเป็นไฟล์เดียว
- ตัวจำลองเข้มงวดกว่าของจริงในจุดเสี่ยง:
  - แปลงข้อความเป็นตัวเลขหรือวันที่อัตโนมัติ ถ้าเซลล์ไม่ได้ตั้งเป็น Plain text
  - ตีความข้อความที่ขึ้นต้นด้วย `=` เป็นสูตร
  - error เมื่ออ้างช่วงเซลล์เกินขนาดชีต

### ทางเลือก: ติดตั้งแบบแยกไฟล์หรือด้วย clasp

**แยกไฟล์:** สร้างไฟล์สคริปต์ใน Apps Script ตามชื่อไฟล์ใน `src/` (`Code`, `Config`, `Shared`, `Utils`, `Db`, `Audit`, `Setup`) แล้ววางเนื้อหาทีละไฟล์

**`appsscript.json`:** ถ้าต้องการกำหนดสิทธิ์และเขตเวลาให้ตายตัว
1. เปิดการแสดงไฟล์นี้ที่ ⚙️ การตั้งค่าโปรเจกต์
2. วางเนื้อหาจาก `src/appsscript.json`

ถ้าไม่วางไฟล์นี้ Apps Script จะหาสิทธิ์ที่ใช้จากโค้ดเอง และระบบกำหนดเขตเวลา Asia/Bangkok ในโค้ดทุกจุดอยู่แล้ว

**clasp:**

1. ติดตั้งและเข้าสู่ระบบ

   ```bash
   npm install -g @google/clasp
   ```

   ```bash
   clasp login
   ```

2. คัดลอก `.clasp.json.example` เป็น `.clasp.json` แล้วใส่ Script ID
3. อัปโหลดทั้งโฟลเดอร์ `src/`

   ```bash
   clasp push
   ```
